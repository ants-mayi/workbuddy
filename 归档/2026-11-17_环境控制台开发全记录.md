## 一、这个项目是什么

一个"本机开发环境控制台"：Flask Web 控制台（13 个面板）+ 命令行工具，用于随时查看本机软件状态、端口、路径、命令库、9 份速查文档，并提供服务启停、缓存清理、环境体检等操作。

**启动方式**：

- `M:\AI\WorkBuddy\env\env-web.bat` → Web 控制台 http://127.0.0.1:8010
- `M:\AI\WorkBuddy\env\env.bat` → CLI（子命令含 services、recap 等）
- 解释器固定用 `G:\workIns\conda\envs\pytorch\python.exe`（默认 python 无 flask）

**架构**：80% 通用引擎（`engine/core.py`、`engine/web.py`、`engine/cli.py`、`engine/index.html`）+ 20% 配置（`config.py` 的 PROFILE）。引擎克隆自 `G:\study\AI\huggingface\_scaffold\` 脚手架（该脚手架同时服务 HF 一条龙控制台 `hfctl`）。

## 三、关键功能实现（值得复用的设计）

### 1. 端口智能自愈（`pick_web_port`）

启动 Web 时检测端口占用：空闲 → 用原端口；占用者是**本项目旧服务**（psutil 查 cmdline 含 `web.py` 且 cwd 在项目 ROOT 及其子目录）→ 自动关闭旧服务并复用端口；其它程序占用 → 端口 +1 顺延。实际端口写入 `.web.port`；CLI→Web 传 `HFKIT_WEB_PORT` 环境变量避免二次决策。

> 坑：`is_project_web` 的 cwd 判定最初太严，HF 从 hfctl 子目录启动时误判为"别的程序"，已放宽为「cwd 在 ROOT 下含子目录」。

### 2. Markdown 文档渲染体系（engine/index.html）

- **标题 id 不依赖 marked**：marked v12 中 `marked.use({heading: fn})` 旧式注册会被**静默忽略**导致标题无 id、锚点全失效。改为渲染后 `querySelectorAll('h1..h6')` 统一按 slug 规则补 id。
- **slug 规则**（GitHub 风格，前端与校验脚本必须同一条规则）：小写、剥离标点（含全角 `（）【】《》、` 等）、**每个空白字符各转一个 `-`**（用 `\s` 不是 `\s+`，连续空格要产生多个连字符）；重复 slug 按 GitHub 加 `-1` 后缀。
- **链接接管**：`#dbody` 事件委托——`#锚点` 平滑滚动，`.md` 链接切换文档 tab（避免 404）。
- **左侧二级菜单**：「速查文档」导航下动态生成 9 个文档条目，点击展开该文档 h1~h3 目录（124 项）；点击目录项 → `show('docs')` → 切 tab → `setTimeout(0)` 滚动到小节。文档内容存 `window.__DOCS` 全局缓存。

### 3. 复制按钮安全模式

命令含单引号时，onclick 内联 JSON.stringify 会被 HTML 解码回引号提前闭合。**正确做法**：`data-cmd="${esc(cmd)}"` + `onclick="copyText(this)"`，从 dataset 取原文。经验：命令/路径进 onclick 字符串是转义地狱，一律走 `data-*` 属性。

### 4. Web 响应禁缓存

`@app.after_request` 设 `Cache-Control: no-store`、去 ETag/Last-Modified——改版后浏览器刷新即生效，杜绝"改了没变化"的缓存问题。

## 七、经验教训（其他对话可引用）

- **marked v12 的 renderer 注册必须用 `marked.use({renderer:{heading(){}}})`**；顶层 `use({heading:fn})` 静默失效。
- **HTML 属性里塞命令/路径一律用 data-* 属性 + dataset 读取**，别拼 onclick 字符串。
- **禁缓存策略（no-store）对开发期 Web 控制台至关重要**，否则每次改版都要解释"浏览器缓存"。
- **PowerShell 5.1 无 `?:` 三元和 `??`**；jsdom 无 rAF；Bash 后台 `&` 启动服务会被安全策略拦截，用 run_in_background 受管任务。
- **外部快捷键/命令资料必须逐条核验**：两份外部手册共核出 10+ 处真实错误（IDE 调试键、播放器键、npm 版本行为等）。
- **文档多处维护要有提示**：06/07 与 `config.py` 的 command_lib、事实源手册是多处维护，文末已标注同步提醒。
- **本机环境信息以 `M:\AI\WorkBuddy\docs\电脑开发环境信息.md` 为唯一事实源**（AI 解释器 `G:\workIns\conda\envs\pytorch\python.exe` 不在 PATH；两套 Conda 拼写不同是关键坑）。
